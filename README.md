C++ Judger - 本地测评工具
# 功能
CppJudge 是一个为算法禁赛而做的一个手动评测器。  
- GUI 选择 C++ 源文件、测评点文件，设置时间/空间限制与 C++ 标准版本
- 每次评测重新读取并编译源文件，编译失败完整反馈报错信息
- 依次运行各测评点，反馈 AC / WA / TLE / MLE / RE 及运行时间与空间
- 使用 Windows Job Object 监控内存并强制终止超限进程，无需 psutil
- 支持深色/浅色模式切换，默认深色
- 测评结果以折叠框展示，默认折叠，展开可查看输入/预期输出/输出/差异比较

# 如何使用
打开 exe 文件后，需选择一下东西：
- 一个需运行文件
- 一些测评点文件
- 编译器所在目录
- 时间限制和空间限制
- 编译器版本

选择完成后，再点击开始评测按钮，就可以开始评测。  

若有无用测试数据，点击无用测试数据，在点击测试数据框右侧的“删除”按钮即可删除。

# 评测
当用户点击 开始评测按钮 后，开始评测。  
每次测评会重新读取 c++文件 和 测试文件，每次重新编译，若编译失败，完整反馈报错信息，不进行后续评测。

编译结束后，按 测评点文件 依次进行测试，每个测评点根据一下反馈：
- 当运行时发生错误，强行中断该测试点的测试，反馈结果：RE。
- 当运行时超过时间限制的 1.2 被，强行中断该测试点的测试，反馈结果：TLE。
- 当运行时使用空间超过 空间限制的 1.2 被强行中断该测试点的测试，反馈结果：MLE。
- 运行结束后，若超过时间限制，反馈结果：TLE。
- 运行结束后，若使用空间超过 空间限制，反馈结果：MLE。
- 运行结束后，若 输出 与 预期输出 不一致，反馈结果：WA，并提供给用户 预期输出，输出 和 差异比较。
- 运行结束后，若 输出 与 预期输出 除行尾空格与结尾输出其他完全一致，反馈结果：AC。
- 除了编译失败，每个测评点运行结束后都要反馈 运行时间 与 运行空间。

# 注意事项
需运行文件只能是 cpp 文件。

评测点文件输入文件是 .in 文件，预期输出文件是 .out 文件，千万不能搞错成 .ans 了。

编译器版本：
- c++11
- c++14（默认）
- c++20
- c++23
