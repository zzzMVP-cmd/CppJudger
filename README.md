# C++ Judger - 本地测评工具

CppJudger 是一个为算法竞赛而设计的本地手动评测器。

## 功能

- GUI 选择 C++ 源文件、测评点文件，设置时间/空间限制与 C++ 标准版本
- 每次评测重新读取并编译源文件，编译失败完整反馈报错信息
- 多线程并行运行各测评点，反馈 AC / WA / TLE / MLE / RE 及运行时间与空间
- 使用 Windows Job Object 设置进程级硬限制并监控内存，无需 psutil
- 使用 QueryPerformanceCounter 高精度计时
- RE 时细分错误类型（段错误、除零、栈溢出等）
- 支持深色/浅色模式切换，默认深色
- 测评结果以折叠框展示，默认折叠，展开可查看输入、预期输出、输出、差异比较
- 差异比较中，缺少的行显示为蓝色（`-`），多余的行显示为红色（`+`）

## 如何使用

打开 `CppJudger.exe`，依次选择以下内容：

1. **C++ 源文件**：点击"选择"按钮，选择一个 `.cpp` 文件
2. **测评点文件**：点击"添加"按钮，一次性多选所有 `.in` 和 `.out`（或 `.ans`）文件，程序会按文件名自动配对（如 `xxx1.in` 配 `xxx1.out`）
3. **编译器路径**：默认为 `D:\zzzMVP\MinGW64\bin\g++.exe`，可手动修改或点击"浏览"选择
4. **时间限制**：单位为 ms，默认 1000
5. **空间限制**：单位为 MB，默认 256
6. **C++ 版本**：可选 C++11 / C++14（默认） / C++20 / C++23

选择完成后，点击 **"开始评测"** 按钮即可开始评测。

### 管理测评点

- **添加**：点击"添加"按钮选择更多文件，已有数据不会丢失，同名文件会被覆盖
- **删除**：在列表中选中一个或多个测评点，点击"删除"按钮即可移除
- **清空**：点击"清空"按钮移除所有测评点

## 评测规则

当用户点击"开始评测"后，开始评测。每次评测会重新读取 C++ 源文件并重新编译，若编译失败，完整反馈报错信息，不进行后续评测。

编译结束后，多个测评点并行运行（线程数自动检测为 CPU 核心数），每个测评点根据以下规则反馈：

| 条件 | 结果 |
|------|------|
| 运行时发生错误 | **RE**（细分错误类型，见下表） |
| 运行时超过时间限制的 1.2 倍（强行中断） | **TLE** |
| 运行时使用空间超过空间限制的 1.2 倍（强行中断） | **MLE** |
| 运行结束后超过时间限制 | **TLE** |
| 运行结束后超过空间限制 | **MLE** |
| 输出与预期输出不一致 | **WA**（提供预期输出、实际输出、差异比较） |
| 输出与预期输出除行尾空格与末尾空行外完全一致 | **AC** |

每个测评点运行结束后都会反馈 **运行时间** 和 **运行空间**（峰值内存）。

### RE 错误类型细分

| 退出码 | 含义 |
|--------|------|
| 0xC0000005 | 段错误 / 非法内存访问（ACCESS_VIOLATION） |
| 0xC0000094 | 整数除以零（INTEGER_DIVIDE_BY_ZERO） |
| 0xC00000FD | 栈溢出（STACK_OVERFLOW） |
| 0xC000001D | 非法指令（ILLEGAL_INSTRUCTION） |
| 0xC0000135 | 找不到 DLL（DLL_NOT_FOUND） |
| 其他 0xCxxxxxxx | NTSTATUS 异常码 |
| 其他 | 通用退出码 |

## 测评精度

- **高精度计时**：使用 Windows `QueryPerformanceCounter` API，精度取决于硬件（通常为纳秒级），远优于 `time.perf_counter`
- **轮询间隔 5ms**：每 5ms 检查一次挂钟时间和峰值内存，确保及时响应超时和超内存
- **Job Object 内存监控**：通过 `QueryInformationJobObject` 获取进程峰值内存，精确可靠

## 注意事项

- 需运行文件只能是 `.cpp` 文件
- 测评点文件中，输入文件后缀为 `.in`，预期输出文件后缀为 `.out` 或 `.ans`，程序会自动识别并配对
- 配对规则：文件名去掉后缀后相同的 `.in` 和 `.out`/`.ans` 配为一组（如 `test1.in` + `test1.out`）
- 编译时默认开启 `-O2` 优化
- 编译器版本可选：C++11、C++14（默认）、C++20、C++23
- 并行评测线程数自动检测为 CPU 逻辑核心数
