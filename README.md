# CppJudger
Windows 平台下简易本地 C++ OJ 判题器。
基于 Win32 API CreateProcess 实现时间、内存限制，读取配置文件完成对代码的编译与评测。

> ⚠️ **安全警告**
本项目**没有沙箱防护**，仅用于本地学习调试，绝对不要部署在公网，恶意代码会破坏你的电脑。

## 文件结构
```
CppJudger/
├── judger.cpp     # 判题核心，进程控制、时间内存限制
├── main.cpp       # 程序入口，读取config.json，执行评测
└── config.json    # 评测配置文件
```

## 环境要求
- Windows 10 / Windows 11
- g++(MinGW‑w64) 需要配置到环境变量
- C++17 及以上

## 编译
```bash
g++ main.cpp judger.cpp -o cppjudger -std=c++17
```

## config.json 配置说明
```json
{
  "src_path": "test.cpp",
  "time_limit": 1000,
  "mem_limit": 262144,
  "in_path": "in.txt",
  "out_path": "stdout.txt",
  "ans_path": "ans.txt"
}
```
- `src_path`：待评测源代码路径
- `time_limit`：时间限制，单位毫秒
- `mem_limit`：内存限制，单位KB
- `in_path`：测试输入文件
- `out_path`：被测程序输出
- `ans_path`：标准答案文件

## 运行
1. 修改 `config.json` 设置你的参数
2. 运行编译出来的程序
```bash
cppjudger.exe
```
程序会输出 JSON 格式判题结果。

## 返回结果状态码
- `AC`：答案正确
- `WA`：答案错误
- `TLE`：时间超限
- `MLE`：内存超限
- `RE`：运行时错误
- `CE`：编译失败

## 注意事项
1. 仅支持 Windows，Linux/macOS 无法运行（依赖 Windows API）
2. g++必须可以在cmd直接调用，否则编译评测会CE
3. 不要用于处理不可信代码，没有安全隔离

# 如何使用
打开 exe 文件后，分别选择一个需运行文件，一些测评点文件，还要选择编译器所在目录以及时间限制和空间限制，还可以选择编译器版本。选择完成后，再点击开始评测按钮~~是叫这个吧~~，就可以开始评测。
# 评测
当用户点击 开始评测按钮 后，开始评测。  
每次测评需**重新读取** c++文件，**重新编译**，若编译失败，完整反馈报错信息，不进行后续评测。  
编译结束后，按 测评点文件 依次进行测试，每个测评点根据一下反馈：
- 当运行时发生错误，强行中断该测试点的测试，反馈结果：RE。
- 当运行时超过时间限制的 1.2 被，强行中断该测试点的测试，反馈结果：TLE。
- 当运行时使用空间超过 空间限制的 1.2 被强行中断该测试点的测试，反馈结果：MLE。
- 运行结束后，若超过时间限制，反馈结果：TLE。
- 运行结束后，若使用空间超过 空间限制，反馈结果：MLE。
- 运行结束后，若 输出 与 预期输出 不一致，反馈结果：WA，并提供给用户 预期输出，输出 和 差异比较
- 运行结束后，若 输出 与 预期输出 除行尾空格与结尾输出其他完全一致，反馈结果：AC。
- 除了编译失败，每个测评点运行结束后都要反馈 运行时间 与 运行空间。
